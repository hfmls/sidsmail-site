기능

이메일 클라이언트가 해야 할 모든 것.
하지 말아야 할 것은 하나도 없이.

메일을 많이 읽고 빨리 처리하고 싶은 사람을 위해 만들었습니다 — 키보드로, 기다림 없이, 소음 없이.

모든 계정을 하나의 편지함에

Gmail, Outlook, iCloud, Yahoo 또는 어떤 IMAP 서버든 나란히. "모든 편지함" 보기가 전부를 한데 모으고, 계정마다 고유한 색상을 유지합니다.

실시간 메일

IMAP IDLE: 메시지가 보내진 그 순간에 도착합니다. 반복 확인 없이. 시스템 트레이에 머물며 배지와 소리로 알립니다 — 원할 때만.

방해 금지 시간과 다시 알림

방해받고 싶지 않은 시간을 정하고, 중요한 발신자는 예외로 두세요. 메시지를 잠시 후, 내일 또는 다음 주로 미뤄 둘 수 있습니다.

키보드로 분류

보관, 삭제, 별표, 이동, 다음 안 읽은 메시지 — 모두 키 하나로. 연산자로 검색하세요: from:, subject:, has:, before:.

Google 또는 Microsoft로 로그인

브라우저에서 로그인하세요. 원래 그래야 하니까요 — 원한다면 앱 비밀번호도 됩니다. 서버는 Sidsmail이 알아서 찾습니다.

당신의 언어로 말합니다

20개 이상의 언어를 Windows 설정에 따라 자동으로 선택합니다. 라이트·다크 테마, 여섯 가지 강조 색상, 답장 템플릿, 단어 수 세기, 스스로 비워지는 휴지통.

갤러리

앱의 안을 들여다보세요.

라이트 또는 다크 테마, 여섯 가지 강조 색상 — 여기서 골라 어떻게 보이는지 확인하세요. 이미지를 클릭하면 크게 볼 수 있습니다.

개인정보 보호

메일은 내 컴퓨터에 머뭅니다.

Sidsmail은 계정의 서버와 직접 대화합니다. 중간에 우리 서버도, Sidsmail 계정도, 원격 측정도 없습니다. 보관하는 것은 오롯이 당신의 것입니다.

  • 외부 이미지 차단이 기본 — 뉴스레터의 추적 픽셀은 허락하기 전에는 절대 로드되지 않습니다.
  • 비밀번호 암호화는 Windows 자체 데이터 보호 기능으로, 사용자 프로필에 연결됩니다.
  • 선택적 PIN 잠금으로 시작할 때와 트레이에서 돌아올 때 보호합니다.
  • 모두 내보내거나 삭제를 클릭 한 번으로 — 데이터는 당신의 것이며, 가져갈 권리도 당신의 것입니다.

유료 코드 서명 인증서가 아직 없는 새 프로그램에서는 정상적인 일입니다. 추가 정보를 누른 다음 실행을 누르세요. 설치 프로그램은 이 페이지에 게시된 파일과 동일하며, 다운로드 페이지에서 크기와 버전을 확인할 수 있습니다.

가장 많이 방문한 10개국

    아직 데이터가 충분하지 않습니다 — 잠시 후 다시 확인해 주세요.

    자주 묻는 질문

    물어보기 전에.

    Gmail에서도 되나요?

    네. Google로 로그인하거나(브라우저에서 클릭 한 번) 앱 비밀번호를 쓰면 됩니다 — Gmail은 어떤 이메일 클라이언트에서든 일반 비밀번호를 거부합니다. Sidsmail만의 문제가 아닙니다.

    Outlook과 Hotmail은요?

    네, Microsoft로 로그인하면 됩니다. Microsoft는 개인 계정에서 앱 비밀번호를 더 이상 받지 않기 때문에 브라우저 로그인이 유일한 길입니다 — 나머지는 Sidsmail이 처리합니다.

    내 데이터는 어디에 저장되나요?

    내 컴퓨터의 %APPDATA%\Sidsmail에 저장됩니다. 계정, 설정, 그리고 오프라인에서 읽기 위한 메시지 로컬 사본이 들어 있습니다. 프로그램을 제거해도 이 폴더는 그대로 남고, 설정의 "로컬 데이터 삭제"가 폴더를 완전히 지웁니다.

    얼마인가요?

    무료입니다. Sidsmail은 무료이며 "Pro" 버전이 없습니다. 한 사람이 여가 시간에 만듭니다 — 유용하다면 후원할 수 있지만, 결코 의무가 아니며 잠긴 기능도 없습니다.

    HTML 메시지가 텍스트로만 보이나요?

    Sidsmail은 Windows의 WebView2로 HTML을 표시합니다. Windows 11과 최신 상태의 Windows 10 대부분에는 이미 들어 있습니다. 없다면 여기서 설치하세요 — 그동안 앱은 모든 것을 일반 텍스트로 보여 주므로 잃는 것은 없습니다.
