機能

メールクライアントがすべきこと、すべて。
すべきでないことは、何ひとつ。

たくさんのメールを読み、手早く片付けたい人のために — キーボードで、待たされず、ノイズもなく。

すべてのアカウントを、ひとつの受信トレイに

Gmail、Outlook、iCloud、Yahoo、あらゆる IMAP サーバーを並べて。「すべての受信トレイ」ビューがひとつにまとめ、各アカウントは自分の色を保ちます。

リアルタイムのメール

IMAP IDLE：送信された瞬間にメッセージが届きます。定期的な確認は不要。システムトレイに常駐し、バッジとサウンドでお知らせ — あなたが望むときだけ。

サイレント時間とスヌーズ

邪魔されたくない時間を決めて、大切な送信者だけを例外に。メッセージは後で、明日、または来週までスヌーズできます。

キーボードで仕分け

アーカイブ、削除、スター、移動、次の未読 — すべてキーひとつ。演算子で検索：from:、subject:、has:、before:。

Google や Microsoft でサインイン

ブラウザーでのサインイン、あるべき形で — お好みならアプリパスワードでも。サーバーは Sidsmail が自動で見つけます。

あなたの言語で

20 以上の言語に対応し、Windows の設定から自動で選択。ライトとダークのテーマ、6 色のアクセントカラー、返信テンプレート、文字数カウント、自動的に空になるゴミ箱。

ギャラリー

アプリの中を見てみましょう。

ライトまたはダークのテーマ、6 色のアクセントカラー — ここで選んで、見た目を確かめてください。画像をクリックすると拡大します。

プライバシー

あなたのメールは、あなたのコンピューターに。

Sidsmail はあなたのアカウントのサーバーと直接やり取りします。間に私たちのサーバーはなく、Sidsmail アカウントもなく、テレメトリもありません。あなたが保存するものは、あなたのものです。

  • リモート画像は既定でブロック — ニュースレターのトラッキングピクセルは、あなたが許可しない限り読み込まれません。
  • パスワードは暗号化して保存。Windows 自身のデータ保護を使い、あなたのユーザープロファイルに紐づけます。
  • オプションの PIN ロックを起動時とトレイから戻るときに。
  • すべてをエクスポートまたは消去、ワンクリックで — データはあなたのもの。持ち出す権利も含めて。

    よくある質問

    お問い合わせの前に。

    Gmail で使えますか？

    はい。Google でサインインする（ブラウザーでワンクリック）か、アプリパスワードを使います — Gmail が通常のパスワードを拒否するのはどのメールクライアントでも同じで、Sidsmail に限った話ではありません。

    Outlook や Hotmail は？

    はい、Microsoft でサインインします。Microsoft は個人アカウントでのアプリパスワードを受け付けなくなったため、ブラウザーでのサインインが唯一の方法です — あとは Sidsmail が引き受けます。

    データはどこに保存されますか？

    あなたのコンピューターの %APPDATA%\Sidsmail に：アカウント、設定、そしてオフラインで読むためのメッセージのローカルコピーです。アンインストールしてもこのフォルダーには触れません。設定の「ローカルデータを消去」で完全に削除できます。

    料金はいくらですか？

    無料です。Sidsmail は無料で、「Pro」版もありません。一人が空き時間に作っています — 役に立っているなら支援していただけますが、義務ではありませんし、制限される機能もありません。

    HTML メッセージがテキストでしか表示されません

    Sidsmail は HTML の表示に Windows の WebView2 を使います。Windows 11 と最新の Windows 10 のほとんどには最初から入っています。ない場合はこちらからインストールしてください — それまでの間、アプリはすべてをテキスト形式で表示するので、何も失われません。
