功能

邮件客户端该做的，它都做。
不该做的，一样不做。

为每天读大量邮件、想快速处理完的人而设计 — 键盘操作，不用等待，没有噪音。

所有账户，一个收件箱

Gmail、Outlook、iCloud、Yahoo 或任何 IMAP 服务器，并排显示。“所有收件箱”视图把一切汇集在一起；每个账户保留自己的颜色。

实时收信

IMAP IDLE：邮件发出的那一秒就送达，无需轮询。常驻系统托盘，带角标和提示音 — 只在你需要的时候。

免打扰时段与稍后处理

设定不想被打扰的时间，并为重要的发件人设置例外。把一封邮件推迟到稍后、明天或下周再处理。

键盘整理

归档、删除、星标、移动、下一封未读 — 都只需一个按键。用运算符搜索：from:、subject:、has:、before:。

用 Google 或 Microsoft 登录

在浏览器中登录，本该如此 — 如果你愿意，也可以用应用专用密码。Sidsmail 会自动找到服务器。

说你的语言

二十多种语言，根据 Windows 设置自动选择。浅色和深色主题、六种主题色、回复模板、字数统计，以及会自动清空的“已删除邮件”。

隐私

你的邮件留在你的电脑上。

Sidsmail 直接与你账户的服务器通信。中间没有我们的服务器，没有 Sidsmail 账户，没有遥测。你保存的，只属于你。

  • 默认屏蔽远程图片 — 新闻简报里的跟踪像素，没有你的许可绝不加载。
  • 密码加密保存，使用 Windows 自带的数据保护机制，并与你的用户配置文件绑定。
  • 可选的 PIN 锁，在启动时和从通知区域恢复时生效。
  • 一键导出或清除全部数据 — 数据是你的，包括随时带走它的权利。

    常见问题

    在你提问之前。

    支持 Gmail 吗？

    支持。可以用 Google 登录（在浏览器中点一下即可），也可以使用应用专用密码 — Gmail 在任何邮件客户端中都拒绝普通密码，不是 Sidsmail 的问题。

    Outlook 和 Hotmail 呢？

    支持，通过 Microsoft 登录。Microsoft 已不再接受个人账户的应用专用密码，所以在浏览器中登录是唯一的途径 — 剩下的交给 Sidsmail。

    我的数据存放在哪里？

    在你电脑上的 %APPDATA%\Sidsmail 中：账户、设置，以及供离线阅读的邮件本地副本。卸载程序不会触碰这个文件夹；“设置”中的“清除本地数据”会将它彻底删除。

    要花多少钱？

    不用花钱。Sidsmail 是免费的，也没有“专业版”。它由一个人利用业余时间开发 — 如果对你有用，可以支持一下，但从不强制，也没有任何功能被锁定。

    HTML 邮件只显示为纯文本？

    Sidsmail 使用 Windows 的 WebView2 来渲染 HTML。Windows 11 和大多数更新过的 Windows 10 都已自带；如果缺少，在这里安装 — 在此期间应用会以纯文本显示一切，不会丢失任何内容。
