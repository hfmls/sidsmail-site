Sidsmail

Política de privacidade

Última atualização: setembro de 2026 · English

O Sidsmail é um programa que corre no teu computador. Esta política é curta porque a resposta a quase todas as perguntas é a mesma: não recolhemos nada.

O que o Sidsmail faz com os teus dados

O Sidsmail liga-se diretamente aos servidores das contas de e-mail que configuras (IMAP para receber, SMTP para enviar), usando as credenciais que lhe dás. As mensagens, os contactos e as definições ficam guardados apenas no teu computador, na pasta %APPDATA%\Sidsmail. Não existe nenhum servidor do Sidsmail pelo meio, nenhuma conta Sidsmail, e nenhuma cópia dos teus dados fora do teu computador.

O que não fazemos

  • Não enviamos telemetria, estatísticas de utilização nem relatórios de erro automáticos.
  • Não lemos, indexamos nem transmitimos o conteúdo das tuas mensagens para ninguém.
  • Não mostramos anúncios nem partilhamos nada com terceiros.

Ligações à Internet que o Sidsmail faz

  • Os teus servidores de e-mail — as ligações que pediste ao configurar cada conta.
  • Google e Microsoft, apenas se escolheres "entrar com a Google/Microsoft": a autorização é feita no teu browser, diretamente com eles, e o Sidsmail guarda apenas o token que eles devolvem, cifrado no teu computador.
  • Imagens remotas em mensagens — bloqueadas por defeito; só carregam quando clicas em "Mostrar imagens".
  • Fotos de contactos (Gravatar) — opcional, desligável nas Definições.
  • Verificação de atualizações — se estiver configurada, o Sidsmail descarrega um pequeno ficheiro de texto de sidsmail.com com o número da versão mais recente. Esse pedido não inclui nenhum dado teu além do que qualquer pedido web inclui (o teu endereço IP, visto pelo alojamento do site).

Este site

O site sidsmail.com é estático, alojado no GitHub Pages, sem cookies e sem ferramentas de análise. O GitHub pode registar dados técnicos de acesso (como o endereço IP) nos termos da política de privacidade do GitHub.

Os teus direitos

Como não guardamos dados teus, não há nada que possamos entregar-te ou apagar do nosso lado. No teu computador, "Exportar dados locais" e "Apagar dados locais", em Definições → Segurança e dados, fazem exatamente o que dizem.
